# Changelog

All notable changes. Versions follow `MAJOR.MINOR.PATCH`; the model version is `__version__` in `src/<package>/__init__.py` and is written into `results/results.json`.

## 0.2.0 - 2026-11-05
- Simulation moved from the HTML prototype to a tested Python package (`src/remarketing_planner`); JavaScript mirror verified by a parity test.
- Segments, schedules, funnel and all constants moved into `data/params.json` (single source of truth for code, prototype and paper); `data/PARAMETERS.md` documents them.
- Figures generated by `make figures`; paper numbers come from `results/results.json`.
- Fixed cross-reference numbers of figures in the paper.
